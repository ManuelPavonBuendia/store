# Proyecto-DAW-POKEDEX


## ARQUITECTURA

Para realizar este proyecto se hizo uso de diferentes técnicas de desarrollo, la primera de ellas es el __vertical slicing__, ya que con ella se puede trabajar de ,amera individual y aislada sin comprometer el resto del proyecto.

La segunda técnica utilizada es la __arquitectura Clean__ esta arquitectura separa el dominio, la infraestructura y la aplicación, gracias a esto dividimos el trabajo, para tener que editar lo mínimo en el futuro.

De esta forma se evita romper la aplicación por completo al desacoplar los componentes.
